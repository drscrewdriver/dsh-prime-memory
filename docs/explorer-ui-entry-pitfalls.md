# 记忆库 explorer 实装坑清单（布局 / 色彩渲染 / 入口注册）

> 来源：0.26.32「记忆库」入口 + L1 查询 + 2D/3D 记忆图整轮实修（2026-11-03，desktop 真机逐轮踩平）。
> 面向：后续给 DSH 插件做 canvas 展示面 / 侧栏入口的人。每条都是**实际付出过返工成本**的坑，不是预防性说教。

## 一、布局

1. **宿主 `main` 面板不给确定高度，`height: 100%` 断链。**
   自研画布组件写 `height: '100%'` 会停在半高——父容器高度未定义时百分比无意义。G6 能"自动满高"是因为它内部自己读容器尺寸，掩盖了同一个问题。修法：外层给视口锚（`calc(100vh - 48px)`），内层 flex 链（`flex: 1` + 父 `flexDirection: column`）才有意义。
2. **canvas 首帧 `clientHeight` 可能为 0。**
   挂载即测量会拿到 0，画布退回默认 300×150。兜底链要写全：`host.clientHeight || host.offsetHeight || 常量`。
3. **三栏并排会把"图"这个主视觉挤成窄条。**
   查询列表 / 图 / 详情同屏时，正确形态是**两态切换**（查询 ↔ 图）+ 图模式内右侧详情可调宽，而不是三栏常驻。用户原话："你看现在图的展示区域折损了多少"。
4. **可调宽面板的拖拽方向符号**：左侧板"向右拖变宽"（dir=+1）、右侧板"向左拖变宽"（dir=-1），提成一个 `startDrag(dir)`，别两处各写一遍各错一遍。

## 二、色彩与渲染

1. **canvas 不吃 CSS 变量。**
   `fillStyle: 'var(--dsh-mem-accent)'` 静默变黑。必须先 `getComputedStyle` 解析成实色（GraphCanvas 已有先例，同款处理）。DOM 浮层（HUD/工具条/悬停卡）才可以直接吃令牌。
2. **贴在暗画布上的 DOM 控件不能继续吃浅色主题令牌。**
   `NButton` 默认深字压在星空底上不可读（"回全图/漂移"看不清事故）。修法：控件层做一个**随渲染主题联动的调色盘**（starry → 半透暗条 + 亮字；白底 → 令牌），且工具条要有实底容器，别裸贴画布。
3. **CSS 兜底色要与绘制主题联动，不能写死令牌。**
   `background: var(--dsh-mem-bg-card, #05060b)` 在浅色主题下解析成**白色**——canvas 被 resize 清空的瞬间露白，就是"白闪"。星空态直接 `#04070f`。
4. **帧缓存（离屏 buffer）blit 时的 DPR 二次缩放。**
   buffer 已是设备像素宽（`w*dpr`），可见 ctx 又带着 `setTransform(dpr,…)`，直接 `drawImage(buffer,0,0)` = 再放大 dpr 倍 → 画面偏右下、点击拾取与视觉对不上。blit 前 `setTransform(1,0,0,1,0,0)`，blit 后恢复。
5. **`useEffect` 启动 rAF 必然比 paint 晚一帧 → 空画布闪烁。**
   改 `useLayoutEffect` + 同步画第一帧（`frame(performance.now())` 后再 requestAnimationFrame）。
6. **"空闲冻结"优化制造白屏，静态场景收益为零。**
   resize 把 canvas 清空但不置 dirty → 下一帧被冻结跳过 → 白屏卡死；而漂移默认关时逐帧重绘结果相同、不会闪。结论：**没有动画就别冻结，永远重绘**。
7. **亮度双通道不能共用一个饱和上限。**
   `alpha = min(1, depthLight × aging)` 在拉近后 depth 项 >1，只要 aging>0.59 全饱和成 1——而 aging 定义域只有 0.5~1，老化差异被深度通道整块吞掉。定式：**各自封顶再相乘**（深度封顶 0.85，老化独占剩余），并给单测钉"极端拉近时两档仍不等"。
8. **`lighter` 混合的辉光在密集簇有亚像素抖动 = 闪烁感。** 默认静态（漂移关）比默认"活着的星空"观感更好，动起来应该是显式开关。
9. **装饰星阵要"三档亮度 + 少数带晕"，不要均匀点阵。**
   劳斯莱斯星空顶的感觉 = 密度按面积（~每 12500px² 一颗、封顶 260）、78% 细淡点 / 17% 中星 / 5% 亮星带径向微晕；全用确定性 hash（同种子恒同星阵），烘进背景缓存零逐帧开销。

## 三、入口注册（slots）

1. **`slots.inject(seat, cb)` 本身就是座位探针。**
   callback 只在座位**被宿主声明**时运行，且能响应**晚声明**；`spec(key)` 只能回答"此刻声明了没"。别引入 spec 探测再自己处理竞态（本轮先写错一次、回退了 `env.ts` 的 `spec?` 声明）。
2. **register 返回 disposer → 运行期可反复挂/拆，入口显隐不该要求重启。**
   照 dshmarket `section-gate` 的模式：`register/dispose` 状态机 + `setVisible(bool)` 即时 apply。"apply 期读一次开关、之后重启生效"是偷懒，不是宿主限制。
3. **同 bundle 的开关与入口用模块级状态单例直连。**
   设置页（OverviewTab）和入口注册（entry.tsx）在同一个 client.js / 同一个 JS 上下文——写成功后直接 `notify`，订阅方当场重算挂载，零通道零轮询。三个细节：
   - 慢到达的**首读不得覆盖用户刚做的选择**（chosen/epoch 语义）；
   - RPC **写失败要连挂载状态一起回滚**（否则行没了、面板还显示已开）；
   - 首读**失败 fail-open**（缺省语义是开，不能因一次抖动锁死入口）。
4. **live 开关有六个写点，缺 schema 那个 = 拨了白拨。**
   contract 类型 / `config.ts` live **Schema** / `settings.ts` 默认值 / sanitize / `stats-get` 响应 / `settings-set` 白名单。schema 外的键被静默丢弃：面板显示"已关闭"、重启后读不回、入口照挂。本轮真机踩过（`explorerEnabled` 五处齐了独缺 schema）。
5. **座位没挂上必须响亮诊断**（setTimeout 判定期 + console.warn），静默消失的 UI 问题长期查不出来（本仓 2026-09-17 旧账）。但"开关关闭导致的不挂载"要置位 `mounted` 类标记，别让诊断误报。
6. **同版本号覆盖装机会命中 pnpm 内容寻址缓存**——新代码根本没进包，看起来像"没编译"。本地迭代一律 `-local.N` 递进换包（market 的 bump-pack 棒同理）。

## 四、验收口径（防自欺）

- "装机成功"不等于"生效"：回读 `node_modules/<pkg>/dist/*.js` 里的**新代码标记字符串**才算。
- 注释会被 bundler 剥掉，MISSING 先想标记形态（变量名混淆/注释），别急着判"没装上"。
- 帧率/观感类结论要在真机读数（HUD 带 BUILD 标记 + rAF tick 计数，能分辨"旧页 / 循环卡死 / 统计未触发"三种假象）。
